# 개인정보 처리방침 (초안)

> 앱에 실제로 구현된 동작을 기준으로 작성한 초안입니다. 법률 검토를 받지 않았으며, `[ ]` 항목을 채우고 검토한 뒤 사용합니다.

## 처리하는 정보

| 항목                                  | 목적                                                                 | 보관 위치              |
| ------------------------------------- | -------------------------------------------------------------------- | ---------------------- |
| 이메일, 비밀번호                      | 회원 가입과 로그인. 비밀번호는 인증 서버가 처리합니다.               | Supabase               |
| 장소 이름, 주소, 좌표, 메모, 태그     | 장소 기록                                                            | Supabase               |
| 출조·식사 기록, 동행 이름, 체크리스트 | 기록과 준비물 관리                                                   | Supabase               |
| 사진                                  | 기록 첨부. 업로드 전에 압축하며 사진의 위치 정보(EXIF)를 제거합니다. | Supabase 비공개 저장소 |
| 현재 위치                             | 지도에서 현재 위치 표시. 서버에 저장하지 않습니다.                   | 기기                   |

인터넷이 끊긴 동안의 변경과 마지막으로 받은 데이터는 기기에 암호화해 보관합니다.

## 외부 전송

| 받는 곳                  | 보내는 정보                | 시점                                       |
| ------------------------ | -------------------------- | ------------------------------------------ |
| Supabase                 | 위 표의 정보               | 저장, 동기화                               |
| Kakao 로컬 API           | 검색어, 지도에서 고른 좌표 | 장소 검색, 주소 변환                       |
| Open-Meteo               | 장소 좌표와 날짜           | 기록 작성에서 날씨·물때 불러오기를 누를 때 |
| Google 지도 / Apple 지도 | 지도 표시에 필요한 정보    | 지도 사용                                  |

## 보관과 삭제

- MY 페이지의 계정 삭제를 실행하면 장소, 기록, 사진, 체크리스트와 계정을 바로 삭제합니다.
- MY 페이지에서 기록을 CSV로, 전체 데이터를 JSON으로 내보낼 수 있습니다.
- 로그아웃하면 기기의 서버 데이터 사본을 지웁니다. 아직 올리지 못한 변경은 다시 로그인할 때 올리기 위해 기기에 남습니다.

## 권한

| ------------ | ---------------- | ---------------------------------- |
| 위치         | 현재 위치 표시   | 다른 기능은 그대로 쓸 수 있습니다. |
| 사진, 카메라 | 기록에 사진 첨부 | 사진 없이 기록할 수 있습니다.      |
